# Triage labels

| Role and GitHub label | Meaning |
| --- | --- |
| `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | The reporter needs to supply more information. |
| `ready-for-agent` | The issue is specified and ready for an agent. |
| `ready-for-human` | The issue needs human implementation. |
| `wontfix` | The maintainers have decided to close the request without implementing it. |

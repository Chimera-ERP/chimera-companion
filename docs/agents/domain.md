# Domain docs

This repository has one context. Use `GLOSSARY.md` at the repository root and read relevant decisions in `docs/adr/` when they exist. Create entries when the team resolves a term or makes a durable decision.

Use glossary terms in issues, code reviews and test names. Flag any conflict with an existing ADR and link to the decision. For business rules shared across services, follow the [canonical ERP documentation](https://github.com/Chimera-ERP/chimera/blob/main/docs/README.md).
